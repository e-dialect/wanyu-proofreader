## 兼容性与回退

- 没有新增 schema，也没有改写历史迁移。Bundle 复用已有 PDF 快照字段；CSV重复确认返回原作业。
- OCR账本新增 `count_unit` 与 `summary.ocr_pages`；`total_rows` 只含输入行，不再把物理页混入。正式 OCR 仍拒绝扫描/混合图页。
- 来源列表保留默认全量形状和排序，超过10,000明确报错。权利变更需完整写入受影响批次的审计，大批影响可能延长该管理员操作的写锁。
- 只接管 failed Bundle 的无人工工作暂存；跨PDF、人工内容、已发布内容不被重绑或覆盖。旧数据的矛盾会明确显示，不能凭重试猜正确来源。
- 回退应用镜像即可回退代码，无 schema down；已写入的真实审计记录、修正和草稿归档保留，不通过回退删除。

代码审查与测试只能证明已覆盖场景的行为，不能证明不存在未知缺陷。授权语料、真实读音、双人 Gold、人工审批和生产容量仍需各自证据。
