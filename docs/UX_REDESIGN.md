# 万语校坊工作台体验重构

## 交付范围

基于 main `80cd5bf`，保留 Vue / PocketBase 和既有后台业务，重新组织全局入口、项目空间与作业界面。独立分支为 `feat/workbench-experience`。本轮仅准备可验收候选，未部署生产、未改真实资料。

视觉采用纸色背景、墨色排版、青绿主操作和少量朱砂标识。全局侧栏稳定呈现工作台、我的任务、项目、来源库；授权及规则归平台设置；个人资料、帮助和退出归账户菜单。15px界面文字和17px校对输入保留原音标/稀有字字体链。

## 页面和旧入口映射

| 原入口 | 当前工作方式 |

项目内部按需加载模块；同项目切换已打开面板保留输入与上传。设置页失败按区隔离；材料与未保存表单离页有明确选择。

项目创建成功直接进入材料准备；失败重试打开已创建项目，不重复创建。PDF通过SPA离页确认后保留已传分片，返回重选同一哈希文件可续传；明确取消仍清理会话，有效期沿用服务端1小时。原生关闭/刷新页面会提示未完成工作，不能保证浏览器允许后台继续传输。

## 接口与数据兼容

没有新增数据库迁移，也没有改变校对、仲裁、核验、编选或交付状态机。本轮包含两项向后兼容的后端修正，候选前后端应配对使用：

- 任务队列新增可选 `filter=all|active|available|reviewed` 和 `project`。省略参数仍返回原有全部授权队列；筛选在分页之前执行，全局摘要口径不变。已提交仅指本人当前轮校对结果，不包含他人、旧轮或仲裁记录。
- Review Bundle 导入保留字段原始首尾空白及 Unicode；只在判断整条是否为空时使用空白检查。不会重写已经导入的历史记录，原有服务端许可、预检、确认与幂等规则继续生效。

资料包入口先执行服务端只读预检，查看声明和错误后才确认导入；前端解包只用于展示声明，服务端负责最终校验。请求结果不明时保留同一包重试，避免误换文件产生重复操作。

## 核心交互

- 桌面原文与字段45/55可调；来源工具合并；键盘可收起并记忆。
- 手机默认字段编辑，原文可展开对照；字符托盘与系统键盘协调，切字段后输入滚入可见区。
- 每字段保留导入值对照；修改后才显示恢复。特殊字符搜索、最近使用、选区插入均保持精确字符。
- 来源状态压为摘要，阻塞和过期依据展开；教程、长说明和历史按需查看。
- 仲裁默认差异，逐字段并列判断；来源复核继续区分未核实、暂缓、正确和错误。
- 归一一次处理一条，旧稿只读，`expected_basis`和409冲突处理保持。
- 来源、导入批次由授权选择器提供；正式交付与各类工作文件保持不同范围及语义。
- CSV复用已有作业时显示服务端实际绑定来源；新选择未应用会明确提示。已知作业进度读取失败可原地重试，不必重新上传。
- 来源复核完成后进入同范围下一条，末条返回复核列表；保存成功但后续队列读取失败时提供继续重试，不再次保存判断。
- 新手提示在页眉按需查看，研究用途决定仍在提交前独立确认。

## 发布准备与回滚

1. 在预发使用临时或经授权的试点资料运行验收；完成上表真人与设备项。
2. 发布前记录生产提交、前后端镜像摘要、API兼容及现有数据库/附件备份位置。本次没有新增数据库迁移；新增队列筛选依赖匹配后端，不能只更新前端后仍运行不识别筛选参数的旧服务。
3. CI按同一提交生成候选镜像，保留上一对已验证镜像与运行配置；生产部署仍须单独明确安排。
4. 验证登录、权限、PDF、领取/提交、仲裁、导入及下载，观察既有日志中的失败与请求延迟。任何输入丢失、会话错位或业务边界错误阻断发布。
5. 回滚切回匹配的旧镜像和配置，保留原数据库及附件，不通过重建数据库回退界面。若跨越已有不兼容接口变更，先按相应升级说明确定配对版本。
