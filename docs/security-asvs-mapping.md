# 本轮 ASVS 适用项与证据映射

版本固定为 [OWASP ASVS 5.0.0](https://asvs.owasp.org/downloads/)。这是本次账户、隔离、审计与交付变更的核查范围，不是完整 ASVS 认证或 L2/L3 达标声明。原文条目分别参见稳定 tag 的 [认证](https://github.com/OWASP/ASVS/blob/v5.0.0/5.0/en/0x15-V6-Authentication.md)、[会话](https://github.com/OWASP/ASVS/blob/v5.0.0/5.0/en/0x16-V7-Session-Management.md)、[授权](https://github.com/OWASP/ASVS/blob/v5.0.0/5.0/en/0x17-V8-Authorization.md)、[安全日志](https://github.com/OWASP/ASVS/blob/v5.0.0/5.0/en/0x25-V16-Security-Logging-and-Error-Handling.md)。摘要以本产品实现为主，具体要求以原文为准。

“通过”指该项所列自动化范围；实际 SMTP、真机、外部身份平台与生产运维边界仍分别验收。测试命令和最终运行结果见产品成熟度证据目录，不能由此表代签。

| --- | --- | --- | --- |

| 6.4.6 | 管理员不能选择用户最终密码 | 未覆盖 L3 要求 | 明确授权的离线临时口令由维护者输入，首次登录强制更换；不能将此称作满足该项 |
| 7.2.1、7.2.2 | 认证由服务端验证动态 token | 通过 | PocketBase 原生协议及账户 HTTP 回归 |
| 7.3.1、7.3.2 | 空闲及绝对登录期限 | 部分 | 延续原生 token 期限；未新增独立空闲会话计时和设备会话管理 |
| 7.4.1 | 各类退出终止原认证 | 部分 | 普通退出沿用本机清除行为，不能撤销已复制 bearer；全设备退出才轮换服务端密钥 |
| 7.4.3 | 账户变更终止其他现有认证 | 通过自动化范围 | logout-all 与改密/重置/邮箱确认，迟到 profile/refresh/bind 不能复活认证；文件token与realtime清auth已测 |
| 7.5.1 | 敏感账户属性更改重新验证 | 通过自动化范围 | 原生改密 oldPassword、邮箱确认 password；自定义 profile 拒绝敏感字段 |
| 7.5.2 | 查看并单独撤销设备会话 | 未覆盖／按计划后置 | 只提供全设备退出，没有设备清单，不冒称完整会话管理 |
| 8.1.1、8.1.2 | 功能、对象、字段权限规则 | 通过本轮范围 | DESIGN.md、账户与交付契约、三种安全事件投影 |
| 8.2.1–8.2.3、8.3.1 | 后端权限及字段白名单 | 通过本轮范围 | profile/native PATCH/batch 防绕过；交付权限先于幂等重放；保护附件访问 |
| 8.3.2、8.4.1 | 撤权与跨项目隔离 | 通过自动化范围 | project_access、pdf_access、delivery、account_security；真实部署代理边界另验 |
| 16.1.1、16.2.1–16.2.5 | 结构化、可关联且脱敏的日志 | 部分 | request_id、JSONL、白名单、365/30天；生产时钟同步与采集权限待运维验收 |
| 16.3.1、16.3.2 | 登录与拒绝事件完整性 | 部分 | 高频拒绝按有界预算聚合；不逐请求写 SQLite，不能称完整逐次取证 |
| 16.3.3、16.3.4 | 变更及安全控制失败可见 | 通过本轮范围 | 账户/权限/交付成功审计同事务；导出授权先于正文，传输结果独立；审计失败降级日志并使报告 incomplete |
| 16.4.1、16.4.2 | 日志注入、读取和篡改保护 | 部分 | JSON 编码、专用事件接口、原生写锁定；主机/数据库管理者仍可改底层数据 |
| 16.4.3 | 独立日志接收系统 | 未覆盖运行验收 | 本轮不部署新遥测平台；部署侧采集和异地验证未代签 |
| 16.5.1 | 异常错误不泄漏内部信息 | 部分 | 新错误不输出密码/token/正文；原有全部接口的数据库/文件错误脱敏尚未逐个覆盖 |
| 16.5.3 | 控制失败时关闭操作 | 通过本轮范围 | 账户/交付审计失败回滚；依据变化/幂等复用/仲裁竞态409 |

第三方身份服务的内部密码策略不在本仓库可验证范围。线上超管 API 的网络访问限制、完整主机安全、独立渗透测试不因关闭管理 UI 而自动通过。未覆盖项保持开放，不通过减少适用范围改成“全部达标”。
