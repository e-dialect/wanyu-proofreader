# 任务项目查找与返回

项目多时，校对者原先只能逐页找项目；查看本人提交后还容易忘记从哪个任务视图进入。本轮延续人类体验方案中的“减少寻找、返回后继续工作”，基于本人提交目录补齐项目搜索。

## 使用过程

- 在“进行中”“待领取”“已提交”中按项目名称搜索。搜索覆盖全部有权参与的项目，再分页；与所选项目和当前视图取交集。名称按字面片段匹配，英文字母不区分大小写，最多 100 个字符。
- 输入后按搜索或回车应用。切换视图保留关键词并回第一页；翻页保留关键词；清除搜索回当前视图第一页。无结果时直接提供清除入口。
- 顶部概况仍统计全部参与项目；下方显示当前条件匹配的项目数。切换条件时不显示可点击的旧列表，刷新同一条件可继续查看原结果。
- 从搜索结果领取或继续校对，返回时恢复视图、关键词、项目范围与页码。连续下一条也保留返回条件；刷新或复制编辑链接到新标签后仍可返回对应列表。
- 本人提交目录的条目号搜索与项目名称搜索相互独立。进入只读回看、换条、返回目录或回到任务大厅时，各自保留条件。
- 练习项目切换任务视图时同步返回的练习步骤；“查看全部参与项目”明确退出当前练习范围，保留项目关键词。

## 交付范围

沿用现有纸墨配色、紧凑表单与按钮。搜索只使用现有权限范围，所有领取和提交条件保持。没有数据库迁移，不新增模糊召回、自动修改原文或任务分派策略。

本机合成走查验证交互；真实使用者仍需判断项目命名是否便于查找、输入与清除是否自然，以及参与更多项目时能否快速继续工作。走查证据见 [记录与截图](../evidence/task-project-search-20261112/README.md)。
