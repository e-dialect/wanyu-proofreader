# 材料准备续接：找回主 PDF、继续导入与核对来源

本切片承接《万语校坊专业团队版：21 天成熟度优化方案》及材料准备减负安排，解决管理员离开后回到项目时不易辨认已有 PDF、无法顺着原文继续 CSV/OCR，以及 Review Bundle 缺来源登记时容易丢失已选资料包的问题。

## 用户路径

### 回到项目继续处理材料

- 项目页显示当前主 PDF 的文件名、已知物理页数和校验信息；旧记录没有页数时明确说明未记录，不将其解释为文件无页。
- 用户可打开原文预览并逐页浏览，随后从同一个项目继续 CSV 导入或 PDF 文字提取。
- 上传替换文件时，已有主 PDF 保持可用；只有新文件通过校验后才成为主文件。上传或校验失败应说明下一步，同时不能覆盖旧主文件。
- 未完成上传提示重新选择同一文件继续；若上传已过期，则提示重新选择并开始上传。此状态不承诺能从刷新前的本机文件自动恢复。

### 检查并登记 Review Bundle 来源

1. 选择资料包并检查包格式与声明信息。
2. 用资料包声明的登记标识检查来源清单。来源不存在时不允许确认导入，并显示可复制的标识。
3. 在新窗口打开来源登记页。项目管理员没有新增来源权限时，应联系平台管理员按该标识登记；不通过此流程扩大角色权限。
4. 保留原项目页和已选 ZIP。登记完成后切回原页，重新检查来源，再继续导入；如果离开或刷新使文件选择丢失，就重新选择资料包并重新检查。

来源登记存在不等于该用途获准。来源及许可信息仍需分别核对；无法确认的声明不能被界面包装为已确认。

## 本轮界面和行为边界

- 使用者能从项目页辨认已有主 PDF、查看物理页并继续材料处理，不必先猜需要进入哪个子页面。
- 失败替换不遮挡当前有效主文件；已显式绑定旧原文的条目继续指向原文件，未绑定的历史条目仍按既有规则使用主 PDF。
- 新窗口登记保留原页内的 ZIP 与检查上下文；手动重新检查后才继续。新窗口只帮助往返，不代表登记结果自动刷新。
- 中文提示采用“当前主 PDF”“预览原文”“资料来源登记”等自然名称，不显示内部流程字母或机器步骤码。
- 资料来源登记权限仍属于平台管理员；此切片不改变导入或交付规则。
- 资料包导入成功后可直接“查看本批条目”，保留本次导入范围，或进入导入批次台账。完成后不再提示仍有未完成资料包。

## 人工走查建议（尚待验收）

- 项目管理员重新打开已有项目，识别主 PDF，预览至少两页，再继续 CSV 导入和 PDF 文字提取，确认仍在原项目中。
- 对缺少历史页数的 PDF 打开预览，确认界面展示读取到的页数，而非错误地呈现为零页或已知值。
- 上传替换 PDF 后模拟校验失败，确认旧主文件仍可预览，用户知道如何重试或继续使用旧文件。
- 项目管理员选择声明来源尚未登记的 ZIP，确认不能导入；在新窗口由平台管理员登记后回原页重新检查，确认不必重新选择 ZIP。再分别核对登记存在和用途许可结论，确认两者没有混为一谈。
- 离开或刷新原项目页后，确认提示如实说明 ZIP 需要重新选择；不把本机文件说成已持久保存。

这些场景是后续真实使用验收清单，不表示真人体验已经通过。合成材料或代码检查也不能代替项目管理员、平台管理员与资料提供方的实际判断。

## 与长期方向的关系

乡声万语希望支持多模态在地文化碎片的知识生成。当前材料准备续接只改善文件可找回、原文可核对、来源可追溯等证据基础；它不宣称已经完成多模态知识生成，也不替资料提供方或接收方判定用途许可。
