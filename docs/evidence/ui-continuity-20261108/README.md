项目数量与材料条数分开显示；“校对完成”不冒充来源核验、质量或交付通过。新条目不会因上一条的成功 flash 显示已提交。服务端确认前不呈现提交成功，确认后立即显示已提交，等待下一条时只显示领取进度。存储失败及租约失效不保证草稿已经落盘。

“总览/提交”只进入总览，不写入；最终动作仍经过核对声明、确认框和原服务端门槛。textarea不因总览、状态或字符托盘切换重建，原字符、空白、光标、选区及草稿保护保留。校对入口仍小于300行。

120/180/220ms令牌用于呈现反馈；没有路由或权限失效的延迟卸载。减少动态效果设置取消菜单/状态入场与字符键缩放。详细规范见[界面契约](../../DESIGN.md)。
