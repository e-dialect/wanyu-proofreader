## 覆盖的排版类型

- 有框表格：❌ 未覆盖（当前两份词典 PDF 均无框线，需补充有框表格样例语料）

## CSV 表头与列角色（#248）

「音读」是逻辑角色，可对应拼音及多个地域 IPA 物理列；不是固定名为「音读」的单列。
打分时保留每个物理列的原名，分别比较，不拼接记音列。完整指标口径见
[README.md「逻辑角色与物理列」](README.md#逻辑角色与物理列)。

2026-10-03 使用标准库 `csv.reader`、UTF-8（兼容 BOM）逐份读取用户提供的受控 CSV
首条记录，核实下列表头；未读取或提交数据行。以下两份不能互相代替，也不能用仓内
合成 fixture 的表头代替真实表头。角色映射按表头语义说明，不改变 gold 的字段表。

| 标准答案 | 完整物理表头（原顺序） | 词头 / 音读 / 释义映射 |
| --- | --- | --- |
| 文读字汇.csv | 汉语拼音、简体字、繁体字、义项、文白读、方言拼音、反切、直音、释义、PDF页码（10 列） | 词头 → 简体字、繁体字；音读 → 方言拼音（汉语拼音、反切、直音为辅助记音列）；释义 → 释义。义项、文白读、PDF页码为额外字段，也分别参与打分。没有 IPA 列。 |
| 莆仙方言大词典（待校对）.csv | PDF页码、词条、拼音、莆田IPA、仙游IPA、释义（6 列） | 词头 → 词条；音读 → 拼音、莆田IPA、仙游IPA（三个独立物理列）；释义 → 释义。PDF页码为额外字段，也参与打分。 |

因此，大词典的核心内容为「词条｜拼音｜莆田IPA｜仙游IPA｜释义」五列，加页码共六列；
文读字汇是另一种十列表头，不能概括为「词头｜拼音｜IPA｜释义」。#120 的三种逻辑角色
与这两种物理列形状兼容，但验收必须分别按十列、六列逐格比较，不能折算成三列或四列。

## 打分脚本使用

```bash
# 从仓库根目录运行；路径按受控语料所在位置替换。
# 每份待测 CSV 须沿用该份 gold 的实际表头；分别打分，不合并「音读」列。
python ocr/score.py --gold "/受控目录/文读字汇.csv" --test "/受控目录/文读字汇-OCR.csv"  # 比较上表全部 10 列
python ocr/score.py --gold "/受控目录/莆仙方言大词典（待校对）.csv" --test "/受控目录/莆仙方言大词典-OCR.csv"  # 比较上表全部 6 列
```

默认按行序对齐；两份表头的页码列均为 `PDF页码`，如需按页码对齐，先确认该列值非空，
再加 `--key PDF页码`。它仍计入比较字段。检查输出的「比较字段」是否与对应 gold 表头一致。
