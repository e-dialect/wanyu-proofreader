## 可观察结果

- 工作台保持一个开始／继续／处理待办入口；正常与忙碌状态不改变操作区域的几何尺寸。
- 桌面短条目有备注约130px，无备注约104px；本地1440×900中前四条完整可见，第四条底边为892px。词目、记音、短释义同基线，备注默认一行，原字段与完整文本仍可展开。
- 320px项目管理主操作为44px高，底边631px，页面无横向溢出；390px也验证主操作与更多菜单同屏。桌面保留语义表格，手机使用同一组表格行，筛选、分页与路由保持。
- 仲裁的“采用某份结果”“最终值”和“来源判断”分别表达。修改最终值仅清除该最终值自己的判断；旧来源、规则不兼容、来源未批准分别自动展开；未决条件继续阻止提交。
- 通用展开支持键盘、关闭内容不可聚焦、受控收起后的焦点返回，保持内容 DOM、原值与选区。减少动态效果时关闭展开动画。
- 状态详情支持触屏查看完整草稿时间及状态依据；不提交、不替换输入节点。修复了详情弹框内提交／邻居快捷键穿透，保留原提交确认层的快捷键和焦点环绕。
